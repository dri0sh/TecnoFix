### Readme FrontEnd
## 1 Instalación del front end 

Comandos necesarios para realizar la instalación

```bash
npm create vite@5 TecnoFix-Frontend -- --template react-ts
```
Despues se debe de entrar a la carpeta con
```bash
cd TecnoFix-Frontend
```
Para luego instalar las dependecias de React

```bash
npm Install
```

## 2 Npm para la dependecias.
En esta sección estarán todas las dependecias que ocuparemos para el proyecto.
La primera dependecia es la siguiente

```bash
npm install react-router-dom
```
